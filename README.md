# Hatchling's Weapon Wheel

A customizable weapon wheel for Queen's Domain.

Hold **Alt**, move the mouse over a weapon, and release Alt to equip it. The world runs at **10% speed** while the wheel is open. Music and effects are pitched down and filtered, returning to normal when you release Alt.

## Controls

- **Left Alt / Right Alt:** hold to open; release to select.
- **Mouse wheel:** change pages.
- **Escape / right click:** cancel.
- **F10:** open or close customization.

Releasing Alt with the cursor in the center or outside the ring keeps your current weapon. The center shows the hovered weapon's icon, or your equipped weapon when nothing is hovered.

## Customization

In F10, click owned weapons to add or remove them. Select a weapon in the ordered list and use **Move Up**, **Move Down**, or **Remove**. **Add All** adds every owned primary weapon. Changes save automatically.

Favorites can span multiple pages, with eight weapons per page by default. Selecting an unequipped weapon replaces the active equipped slot; the normal three-slot cycling still works. Throwing weapons are not included. The F10 menu also slows the world to 10%; it does not pause combat.

## Installation

1. Close Queen's Domain.
2. Download the mod ZIP from [Releases](https://github.com/Ethan0429/queens-domain-weapon-wheel/releases/latest) and extract the entire ZIP.
3. Double-click `Install.cmd`. It searches Steam libraries first, then other installation locations. If it cannot find the game, enter the game folder or executable path.
4. Confirm the displayed installation path. If UE4SS is missing, the installer asks before downloading and installing **UE4SS 4.0.0**. Existing UE4SS installations are kept regardless of version.
5. When installation finishes, press any key to close the installer and start the game.

The ZIP includes the installer and all mod files. An internet connection is needed only if UE4SS must be downloaded. Fresh UE4SS installs include the loader and shared helper library; optional bundled mods are not installed. Existing copies of the mod are backed up, and favorites and other mods are preserved. Always close the game before updating.

You can also supply a path directly; the installer still asks for confirmation:

```text
.\Install.cmd -GameDirectory "C:\path\to\game"
```

### Manual installation

Install [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/v4.0.0) in `QueensDomain\Binaries\Win64`, with `dwmapi.dll` beside the game executable and the remaining loader files in `ue4ss`. Copy `Mods\HatchlingsWeaponWheel` into `ue4ss\Mods`. The included `enabled.txt` enables the mod; no changes to `mods.txt` are needed.

When upgrading from 0.1.0 manually, first remove `ue4ss\Mods\QueensWeaponWheel`. The installer backs up and removes that old folder automatically. Existing `mods.txt` files are left unchanged during installation and removal.

## Configuration

Favorites are stored separately from game saves:

```text
%LOCALAPPDATA%\QueensDomain\Saved\WeaponWheel\config.lua
```

F10 edits apply immediately. To change `slots_per_page` manually (4-12), close the game, edit this file, and restart.

## Artwork

The UI textures in `Mods\HatchlingsWeaponWheel\Assets` are generated by `tools\generate_assets.py` (Python 3 with Pillow and NumPy). Geometry shared with `Scripts\ui.lua` is marked in both files; regenerate after changing it:

```text
py -3 -m pip install pillow numpy
py -3 tools\generate_assets.py
```

## Removal

Close the game and delete `ue4ss\Mods\HatchlingsWeaponWheel`. Or run `Uninstall.ps1` with the same `-GameDirectory` argument. Saves and wheel configuration are retained.
